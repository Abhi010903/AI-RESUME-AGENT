# Security Policy — AI Resume Agent

## Supported Versions

AI Resume Agent provides security updates for current releases:

| Version | Supported          |
| ------- | ------------------ |
| >= 6.0  | :white_check_mark: |
| < 6.0   | :x:                |

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability in AI Resume Agent, please report it privately:

- Submit a private vulnerability disclosure report through your repository hosting provider.
- Provide clear technical details including steps to reproduce, impact assessment, and proof of concept.

All confirmed security issues are triaged, addressed, and released promptly.

## Open Source Compliance
