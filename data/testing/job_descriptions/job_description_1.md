# Junior Gen AI Engineer — OceanAI

## Role Overview
- **Company:** OceanAI
- **Role:** Junior Gen AI Engineer
- **Employment type:** 6-month internship followed by potential full-time conversion (PPO), based on performance
- **Location:** Kochi / Mumbai, based on business requirements
- **Internship stipend:** INR 25,000
- **Full-time CTC:** INR 7,00,000–10,00,000

- **Registration deadline:** The supplied posting says registration closes in 2 days; no calendar date was provided.

## About the Role
OceanAI is looking for curious, thoughtful graduates to join as Junior Gen AI Engineers. The role involves building web applications, APIs and AI-powered features alongside experienced engineers, using modern AI coding tools (including Claude Code) as part of everyday workflows.

The role emphasizes judgment: understanding problems deeply, designing sound solutions, and verifying that implementations work, rather than simply accepting AI-generated code.

## Technical Requirements

### Programming — one of the following
- **Python:** Ability to build and test a small web API using FastAPI or Flask, with basic async programming and pytest.
- **TypeScript with React or Angular:** Ability to build screens that call REST APIs.

### Backend and Software Engineering
- REST APIs and HTTP fundamentals: JSON, status codes and token-based sign-in.
- SQL and relational databases such as PostgreSQL or SQL Server: joins, transactions and the purpose of migrations.
- Git: branches, merges and resolving conflicts.
- Basic understanding of the software development lifecycle (SDLC).

### LLM and Agent Fundamentals
- Calling a hosted model API.
- Writing prompts and obtaining structured JSON output.
- Tool or function calling.
- Building a simple agent loop (plan, act, check the result).
- Evaluating whether model output is correct.
- Frameworks are optional; examples listed include LangGraph, LangChain, AutoGen and CrewAI, in Python or Node.js. Understanding the underlying concepts is valued more than familiarity with a particular framework.

### AI Coding Tools
Ability to use AI coding tools fluently while reading, testing and debugging generated code instead of accepting it without verification.

## Good-to-Have Skills
- Cloud experience; Azure is preferred (app hosting, storage, managed PostgreSQL and Entra ID sign-in), or experience with another cloud platform.
- Docker.
- Browser test automation using Playwright or Selenium.
- Security fundamentals: sign-in and tokens, keeping secrets out of code, and awareness of common web vulnerabilities.

## Desired Mindset
OceanAI values candidates who:
- Think deeply before executing and weigh trade-offs before writing code.
- Enjoy continuous learning and exploring new tools and approaches.
- Look for better ways to build efficient architectures and workflows.
- Care about software craftsmanship and are excited to work in AI.

## Eligibility Criteria
- Final-year B.Tech students in Computer Science & Engineering (CSE) or Information Technology (IT), graduating in 2027.
- Minimum CGPA of 6.5 or above, up to the latest semester.
- Minimum 70% in both 10th and 12th standard (or equivalent).
- Education gap of no more than 1 year.
- No active backlogs at the time of joining.
